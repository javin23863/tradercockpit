Strategy-Claim Audit Checklist

Use this checklist to judge whether a strategy claim can be checked: not whether it will make money, but whether its evidence is traceable, kept apart from the data used to find it, and judged by rules set before the results.

Claim, in its exact words
Source or creator
Date seen

One rule: a polished chart is not proof. Check what was fixed before the result, which data helped find the strategy, how many versions were tried, and which data has never been looked at.

The rules were set before the results

Were the entry and exit rules, settings and pass/fail thresholds written down before testing, and not quietly changed afterwards?

Every number can be traced

Can each number be traced to a specific test, with the timeframe and symbol matching what is being discussed?

Some data was held back

Was a final test period set aside at the start and left untouched until the very end?

Data that was looked at stays used

Once results from a period have been seen, is that period kept out of any later “confirmation”? Re-slicing the same data does not make it new.

Every attempt was counted

Are all the versions that were tried disclosed, including the ones that failed, and not just the winner?

It beats a fair comparison

Was the result compared with what luck alone would produce after trying that many ideas?

Early wins stay provisional

Is a pass on data that had already been looked at still treated as a lead to investigate, not as proof?

The deciding test looks forward

Is any claim that the strategy is ready based on results collected after the rules were frozen?

Paper and live use the same rules

Does the strategy follow the same rules in paper and live trading, with trades that match when the same period is replayed?

The explanation can be checked

If the claim explains why it works, can each step be observed, and does the effect also show up in a related market?

It is presented honestly

Does it avoid profit promises, testimonials and unverifiable numbers, and keep “we checked this” separate from “this will make money”?

Stop: cannot be checkedKey information is missing: the original rules, the held-back data, the number of attempts, or forward results.
A lead, not proofThe evidence comes from data that was used to find or tune the strategy.
Forward-testedResults collected after the rules were frozen are on record. This is still not a promise of future returns.
