How to Export a Strategy to Pine Script

Open the strategy in Results, choose Export, then Retest on TradingView timing, and save the retest’s code as a Pine Script v6 file. The retest acts at each bar’s close and fills at the next open, as a TradingView chart does, so the script trades the way its backtest did.

What you need

A strategy in Results, saved with its settings

  • A Builder strategy open in Results, on a paid plan.
  • A TradingView account to paste the script into, if that is where it is going.
Steps

Retest, then export

  1. Open the strategy in Results. Pick the one you want to take with you.
  2. Open Export and choose Retest on TradingView timing. It is under Strategy code. It tests the strategy again on TradingView’s timing, with no spread or slippage, and saves that run beside the original. A full backtest runs, so it takes a moment. Cancel retest stops it and adds nothing.
  3. Compare the two runs. The retest has different fill timing and no spread or slippage, so its numbers differ from the original’s.
  4. Save the Pine. In the retest’s Code view, press Save to file and choose Pine Script v6. You get a .pine file.
  5. Paste it into TradingView. Open the Pine Editor there, paste the script and add it to a chart of the same symbol and timeframe.
Refusals

Why an export can be refused

The export is refused when the Pine could not match the test, with one of three reasons: the strategy was saved without the settings it was tested with, it was tested on rules that act when a bar opens, or it was tested with a spread or slippage that Pine’s fills don’t have. The retest in step 2 fixes all three.

To build for TradingView from the start, set Platform rules to TradingView timing in Builder’s Setup. Everything the search keeps is then already on that timing.

Mismatches

Differences to expect in TradingView

  • Different bars. The script matches the strategy’s rules and timing, but your TradingView chart’s data is its own.
  • Numbers. Quote the retest’s results for the script, not the original run’s.
  • Costs. The retest has no spread or slippage, so set commission and slippage in TradingView’s strategy properties.
Questions

Questions about Pine export

What else can a strategy be written as?

The Code view also writes EasyLanguage, MetaTrader and Python.

Why not export the first backtest directly?

It may have traded on timing or costs a TradingView chart doesn’t use, and then the script’s trades would not match its backtest.

Can I test a Pine script inside Trader Cockpit instead?

Yes. Run it on your own data with the Strategy Tester.
