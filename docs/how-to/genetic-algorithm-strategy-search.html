How to Run a Genetic Algorithm Strategy Search

In Builder’s Setup, open What to search for, set the search method to Genetic evolution, and press Run. Builder makes strategies from the rule parts you allow, crosses and mutates the fittest each generation, and saves the ones that pass your keep rules to the Kept list.

Steps

Set up and run a genetic search

  1. Open Builder, then Setup, and pick the market. Under Market data, choose history saved on this computer. Press Use this market to bring in its costs.
  2. Open What to search for and set the search method. In Search method’s settings, How to search is Random search or Genetic evolution. Choose Genetic evolution.
  3. Open the Search step. It appears once Genetic evolution is chosen, in four parts: Size and islands, Initial population, Each generation and Start over.
  4. Set the size. Population size (per island) starts at 100, Islands at 4 and Max generations at 100. Strategies move between islands every 87 generations, 6% at a time.
  5. Set how each generation breeds. Crossover probability starts at 93% and Mutation probability at 30%. Replace look-alike strategies with new ones is on.
  6. Choose the rule parts. On Rule parts, turn signals, indicators, stop and limit prices, entry orders and exits On or off. Chance makes a part come up more often; Must use puts it in every strategy.
  7. Set the keep rules and when to stop. On Scoring and filters, fitness starts as return to drawdown, and a strategy is kept only with more than 2 trades a month, a profit factor above 1.3 and return to drawdown above 4. The search stops when the Kept list is full, 1,000 to start, or never, after a number pass, or after a time limit.
  8. Press Run, then Run again to confirm. Pause and Stop work while it runs.
While it runs

What the Run tab shows

  • Tried, Passed the filters, Dropped, Tried per hour and Time per strategy.
  • Leaders: the leader, the runner-up and number 3 so far.
  • Fitness evolution by island, generation and population.
  • Why strategies were dropped, with each reason’s share.
  • When it ends, the strategies are on the Strategies tab, in Kept, with the last generation in its own list.
What can go wrong

When a genetic run keeps nothing

  • No market: Builder asks you to pick a saved market, or save one in Data organization.
  • Too little history: when the dates cover only a short stretch, Builder warns that few strategies will trade enough to be kept.
  • A full Kept list: the run finishes at once. Empty the list or raise Largest list size, then run again.
  • Nothing kept: the run names the main reason strategies were dropped.
  • No volume in the data: rule parts that read volume can’t be used. Turn them off.
  • Settings are locked while a run is going.
Luck

Why the best result needs more testing

A genetic search keeps whatever scored best among everything it tried. The more strategies it tries, the more likely the best scores are partly luck. Treat the Kept list as candidates and test them on data the search never saw: held-back dates, other markets, worse costs. Selection bias explains why.

Questions

Genetic search questions

Random or genetic?

Random search tries new strategies each time. Genetic evolution builds each generation from the best of the last one.

Is there a quick start?

On a paid plan, Getting started has Find strategies on BTC/USD: it saves Coinbase BTC/USD daily bars, sets them in Builder and starts the run.

Where does it run, and for how long?

On your PC, with no time, count or credit limit on a search on any paid plan: it stops on the stop condition you set. The one cap is on a workflow with a Repeat from a step step, which stops after one hour and says your plan’s run time limit was reached; the strategies it kept stay usable.
