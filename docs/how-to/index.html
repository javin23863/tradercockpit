Lesson contract

Every How-To follows the same shape.

1 · Goal

State the outcome first

A user should know in one sentence whether this is the lesson they need.

2 · Steps

Written instructions stay primary

Short, exact steps with expected states and screenshots when public-ready.

3 · Understand

Link the underlying method

The lesson explains why the step exists by linking to Concepts and Methods.

4 · Video

Click to load

Video is optional and lazy-loaded so it does not add tracking or bandwidth until requested.

5 · Recovery

Common mistakes and troubleshooting

Failure states belong next to the workflow, not hidden in a separate support maze.

6 · Reference

Exact Docs handoff

When the user needs field-by-field detail, the lesson links to the precise verified reference page.
