How to Walk-Forward Test a Trading Strategy

A walk-forward test fits a strategy’s settings on one window of history, trades the next window it has not seen, then slides forward and repeats. In Trader Cockpit you turn it on as a stress test in a workflow step and read the score in Results.

What you need

A strategy with settings to re-fit, and long history

  • A Builder strategy with settings worth re-fitting, such as a period or a level.
  • A long saved history. Every run needs its own in-sample and out-of-sample window, each with enough trades to count.
Steps

Turn it on, set the windows, run, read

  1. Open your workflow in Workflows. Use the copy that built or tested the strategy, so the walk-forward runs on the strategies it kept.
  2. Turn on the walk-forward check. Open the Test strategies step that follows the checks the strategy already passed, or add one. In its stress tests, turn on Walk-forward optimization. For the wider version, turn on Walk-forward matrix, which repeats the test across many window layouts.
  3. Set the windows. As a share: Out-of-sample % and the number of Runs. Or as a length: In-sample days and Out-of-sample days, or the same in bars.
  4. Press Run and confirm. It runs like any other step.
  5. Open the strategy in Results, then Walk-forward. The card “Walk-forward run” gives the result and a score. The score is the share of checks that passed.
  6. Read the matrix, if you ran one. “Walk-forward matrix result” says how many window layouts passed, names the best block and suggests a setup with its in-sample and out-of-sample lengths.
  7. Change the pass rule only on purpose. Use the suggested checks, or edit them, and the screen is worked out again. The result saved with the strategy does not change.
Reading it

How to read a walk-forward result

Look for a strategy that passes at more than one window layout, where neighbouring layouts give similar answers. A single passing layout surrounded by failures is the walk-forward version of a lucky setting.

Mistakes

How a walk-forward test can be overfit too

  • Trying window sizes until one passes, then reporting only that one. The matrix shows all of them at once.
  • Out-of-sample windows so short that each holds only a few trades.
  • Looking only at the total. Check how many runs were profitable.
  • Treating walk-forward as the only test. The other checks ask other questions.
Questions

Questions about walk-forward testing

What is the difference between walk-forward optimization and a walk-forward matrix?

Walk-forward optimization is one layout: one in-sample length, one out-of-sample length and a number of runs. The matrix runs many layouts and shows which ones pass.

Can I start a walk-forward from Results?

No. Walk-forward results come from a workflow and are saved with the strategy. Results shows them and lets you change the pass rule.

What if Results says no walk-forward results are saved?

That strategy has not been through a walk-forward check. Turn the check on in its workflow and run it.
