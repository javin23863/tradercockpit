Your privacy on the TraderCockpit website

This page explains what the TraderCockpit website sends to third-party services and when those connections occur.

Same-origin searchWaitlist submits to KitYouTube only after actionReviewed 2026-09-11
Ordinary browsing

The site's own scripts do not set browser storage.

The current public code does not call document.cookie, localStorage, sessionStorage, or IndexedDB. Normal page and asset requests still reach the site's hosting service.

Search

Help search uses a same-origin static index.

Search loads search-index.v1.json from this site. In-app search handoff uses a URL fragment so the query is not sent to a third-party search provider.

Waitlist

Submitting the form sends the entered fields to Kit.

The waitlist posts the email address, optional first name, and source/UTM attribution fields to app.kit.com. The current form does not ask for payment, brokerage, or trading-account information.

Video

YouTube is optional and click-to-load.

No YouTube player is requested on ordinary lesson load. Choosing “Load video from YouTube” creates a privacy-enhanced youtube-nocookie.com embed; following the research-channel link also leaves this site for YouTube.

Waitlist fields

Send only what the form asks for.

The public waitlist asks for an email address and optionally a first name. Hidden attribution fields record source and UTM values so signup origin can be distinguished. Do not put passwords, brokerage credentials, financial records, or other sensitive material into these fields.

Third-party services

Third-party services receive data only when you use them.

Submitting the waitlist form, loading YouTube, or opening an external link sends a request to that provider. Their own privacy terms then apply.

Changes to this page

We will update this notice when the site adds a new data-sharing integration.

If TraderCockpit adds a new form processor, analytics service, media host, checkout provider, or similar integration, this page will identify it.
