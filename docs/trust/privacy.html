Your privacy on the TraderCockpit website

This page explains what the TraderCockpit website sends to third-party services and when those connections occur.

Same-origin searchNo email captureYouTube only after actionUpdated 2026-10-05
Browser storage

Optional research notes use this browser's local storage.

Ordinary browsing does not set cookies or analytics storage. The research-notes tool reads localStorage so it can restore a saved copy and writes only when you choose “Save on this device.” Those notes are not sent to a server by that tool. Clearing browser data can remove the saved copy. Normal page and asset requests still reach the site's hosting service.

Search

Help search uses a same-origin static index.

Search loads search-index.v1.json from this site. In-app search handoff uses a URL fragment so the query is not sent to a third-party search provider.

Analytics

Plausible runs only when configured.

Analytics is currently pending an operator account. When active, Plausible receives page views, referral and UTM information and Guide Click events to measure visits and onward reading. It does not collect an email address through this site. Referral attribution is unavailable until analytics is active.

Video

YouTube is optional and click-to-load.

No YouTube player is requested on ordinary lesson load. Choosing “Load video from YouTube” creates a privacy-enhanced youtube-nocookie.com embed; following the research-channel link also leaves this site for YouTube.

Email capture

This site has no signup form.

Public email-capture forms and signup tracking have been retired. Ordinary browsing makes no requests to Kit. Existing subscriber records have not been deleted by this website change.

Third-party services

Third-party services receive data only when you use them.

Configured analytics, loading YouTube, or opening an external link sends a request to that provider. Their own privacy terms then apply.

Changes to this page

We will update this notice when the site adds a new data-sharing integration.

If TraderCockpit adds a new form processor, analytics service, media host, checkout provider, or similar integration, this page will identify it.
