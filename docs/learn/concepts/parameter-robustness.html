Parameter robustness: how sensitive is a strategy?

Learn why a broad neighborhood of similar behavior is usually more informative than one isolated optimized point.

By the Trader Cockpit team. Educational material, not financial advice.

Read the method

What is it?

Parameter robustness: Parameter robustness examines how a measured response changes across a neighborhood of parameter values. A broad plateau suggests lower local sensitivity than a narrow spike, but the interpretation still depends on the metric, data, search process, and parameter meaning.

What question does it help answer?

Does the observed behavior persist when nearby parameter choices change, or does it depend on one narrow setting?

What can it tell you?

  • Whether nearby parameter values produce similar or sharply different measured behavior.
  • Where a selected point sits relative to broader surface geometry.
  • Which parameters or regions appear locally sensitive and deserve additional validation.

What can it not tell you?

  • A smooth surface does not prove the underlying strategy is valid.
  • A plateau can arise from an insensitive or uninformative metric.
  • Parameter searches can still introduce selection bias even when the chosen region looks broad.
