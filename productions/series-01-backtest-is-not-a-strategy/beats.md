# E1 Beat Map

Title: **You Don’t Have a Trading Strategy — You Have a Backtest**  
Thumbnail: **DON’T TRADE THIS**  
Target runtime: about eleven minutes

| Time | Beat | Viewer payoff |
|---|---|---|
| 0:00–0:03 | Known ident | Fixed `YOU ARE THE MARKET` gauge sweep |
| 0:03–0:45 | The green line | Defines a backtest as a replay and pays off `DON’T TRADE THIS` |
| 0:45–2:10 | The green-line trap | Shows the answer-sheet problem before introducing the process |
| 2:10–3:30 | Start before the chart | Defines a strategy as a written plan and translates “hypothesis” into “your reason” |
| 3:30–5:05 | Make the idea answer questions | Uses one moving-average example and stamps the unfinished rule `NOT READY` |
| 5:05–6:30 | Version A and Version B | Shows how a changed sell rule becomes a new version |
| 6:30–8:00 | Give the backtest a real job | Shows old prices, hidden prices, matching screens, and live fake money |
| 8:00–9:05 | The whole path | Places the green curve under `OLD PRICES` with every later question still open |
| 9:05–10:20 | Series promise | Exact rules, visible results, visible failures, no secret strategy for sale |
| 10:20–11:05 | Viewer action | Writes the reason and the condition that proves the idea wrong |

## Filming boundary

The moving-average sequence is a construction exercise. The two illustrated graphics stay labeled
`EXAMPLE ONLY`; no test outcome is presented as real. The episode remains non-computational unless
the operator separately authorizes a governed test.
