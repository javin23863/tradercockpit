## Fill and slippage

# receipt: E03-C08
A fill is the price the trade gets when the order enters or exits. Imagine a signal at the end of a bar: the fill is the price attached to the actual entry or exit.

# receipt: E03-C09
A backtest often uses the signal price as if that were the fill. That is convenient for calculation, but it can make a trade look cleaner than the path a real order takes.

# receipt: E03-C10
Slippage is the gap between the price you expect and the price you get. A small gap changes the dollars won or lost on every trade, so a long run can feel that gap many times.

# receipt: E03-C11
Here the test moves the entry one bar in the same direction. That gives the fill price a simple stress. Every candidate gets the same treatment, which makes the comparison repeatable.

# receipt: E03-C12
The test answers one question about the fill. The test does not model every broker or every order. The controlled comparison is valuable on its own. It says nothing about a particular execution desk.

## Latency is a different question

# receipt: E03-C13
Latency is the time from the signal to the fill. If the market moves while an order is waiting, that time can change the price of the trade.

# receipt: E03-C14
Slippage is price. Latency is time. Both can change an entry. Keeping the words separate helps us ask the right question about the test.

# receipt: E03-C15
This one-bar move stands in for a later fill. The shift gives a repeatable stress for the recorded test. The same shift is applied across the candidate list, so the result is comparable.

# receipt: E03-C16
A rule that needs the perfect entry has a timing weakness. This check makes that weakness visible. The weakness can be small in one trade and large across a population.

# receipt: E03-C17

# receipt: E03-C18

# receipt: E03-C19
A session half is one of those groups. It tells us whether the result leans on one part of the day. A strong combined result can hide a weak morning or afternoon group.

# receipt: E03-C21

## Profit factor as one diagnostic

# receipt: E03-C38
Profit factor compares the dollars won with the dollars lost in the same set of trades. The numerator is gross winning dollars; the denominator is gross losing dollars.

# receipt: E03-C39

# receipt: E03-C40
