# TraderCockpit teaching series

Use this skill for `Into the Laboratory` scripting, teaching visuals, production, and recovery.
The current lane is a five-episode AI-written, operator-reviewed series; it is not the retired
2026-07-24 concept-stage/on-camera workflow.

## Authority and freshness

Use this order:

1. Current operator direction in the active task and recent production-review tasks.
2. Exact live scripts, scene plans, assets, provider receipts, hashes, and playable outputs.
3. The existing ops-vault production standard, series map, and production plan after checking their
   dates and reconciling them against items 1–2.
4. Repository skills and handoffs as implementation guidance only.

The graph is discovery only; open every cited source file before relying on it. Generated vault
status, old handoffs, and automated GREEN receipts never override newer operator decisions or the
actual artifact. If the sources conflict, stop production and update the existing authority first.
Do not create another plan, workflow, gate, or spec to paper over the conflict.

Current vault entry points:

- `GTM/Social-Media-Library/Into the Laboratory — Production Standard.md`
- `GTM/Videos/Into the Laboratory — Series Map.md`
- `GTM/Videos/Into the Laboratory — Series Production Plan.md`

## Provider route

Teaching-series work does not use `tradercockpit-free-media`. The current route is quality-first
Higgsfield Max under the exact existing provider/model/voice/treatment/credit approvals. Do not
substitute local/free media to save credits. Reuse accepted Higgsfield and narration assets first;
generate only a missing delta. A new subscription, top-up, or spend beyond the approved scope still
requires separate operator authorization.

## Content contract

- AI writes the script; the operator reviews and is the final creative approval.
- Every mathematical, financial, or empirical claim has a private academic/ontology receipt before
  narration. Viewer-facing words remain plain English and define necessary terms.
- Mathematics, charts, empirical results, and evidence are deterministic. Higgsfield supplies
  cinematic identity, context, and purposeful atmosphere—not factual proof.
- Every spoken concept is taught by a sentence-bound visual: worked chalkboard/draw-on arithmetic,
  a deterministic chart, a definition card, or real trader context. Decorative motion does not
  satisfy the visual.
- Each episode keeps its distinct lesson and visual argument. Do not reuse one generic scene
  template across the series.
- Remove defects at the shared generator or source route, then rebuild generated compositions;
  never hand-edit generated scene files.
- Automated gates certify technical facts only. Show the operator a short playable semantic proof
  from the actual composition path before a full-length render.

## Execution boundary

Use the installed OpenMontage skill for its pipeline contract, but execute only from this
repository's `OpenMontage/` checkout. Preserve dirty work and accepted artifacts. Do not publish,
upload, schedule, top up, or mutate live profiles without explicit authorization.

Update the existing episode and `productions/_series/` artifacts in place. Do not create a new
series plan when the requested information already exists.
